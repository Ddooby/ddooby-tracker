- `🧪`: 테스트 통과 필수, `👀`: 사용자 실기기 확인, `🔍`: Codex 독립 리뷰, `⛓`: 선행 태스크.
- 완료 기준을 **실제로 입증한 후에만** `[x]`로 변경. 각 태스크에 검증 커밋·환경·명령/결과·실기기 결과를 남긴다.
- 한 번에 하나의 미완료 태스크를 진행. 브랜치는 `feat/<태스크ID>-<요약>`; Codex는 결과 파일만 작성한다.
